An agent asks for a secret. macOS raises a Touch ID prompt naming the agent and the secret, and
the value goes into one child process rather than into the agent.

Entry names live inside the ciphertext. The private key is sealed to the Secure Enclave, so a
copy of the store is inert on any other machine. Every release is audited.
